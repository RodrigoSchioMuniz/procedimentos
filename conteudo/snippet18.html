Progressive Web Application

É possível instalar um site. isso já não é nenhuma novidade. O chrome lançou o suporte a progressive web application a muito tempo atrás.

O chrome instala o site no dispositivo

Uma pwa tem muitas vantagens em relação a um site. E não é muito complicado fazer o 'upgrade'.

Simples alteração no html

Basicamente o html css e javascript de sempre vai com alguns arquivos extras que indicam ao chrome que os usuários podem instalar o site. E isso traz algumas vantagens como por exemplo um ícone na tela principal do dispositivo.

Como todo site, precisa estar em um server.
No html o chrome é direcionado para executar o arquivo serviceworker.js que pode conter instruções a serem executadas no momento da instalação do site.

O arquivo manifest.json linka os ícones fornecidos.

Arquivos adicionais

Além do site funcional/funcionando são necessarios 4 arquivos que indicam ao chrome a possibilidade de instalar. Existem alguns detalhes e algumas regrinhas que esse tutorial vai mencionar porque apresenta uma versão mínima.

A página index.html contém código html comum. As chamadas ao serviceWorker e ao manifest são pequenas.

<head> 
<link rel="manifest" href="./manifest.json">
</head>

e antes do </body>
<script> 
if("serviceWorker" in navigator){
	window.addEventListener("load",()=>{
		navigator.serviceWorker.register("./serviceworker.js")
		.then(()=>console.log("Registro Ok!"))
		.catch((err)=>console.log(err));
	});
}
</script>

O arquivo serviceworker.js

self.addEventListener("install",(event)=>{
	console.log("install");
});

self.addEventListener("fetch",(event)=>{
	console.log("fetch");
});

O arquivo manifest.json

É importante que o arquivo manifest.json esteja na mesma pasta que o arquivo index.html
Não vale subdiretório

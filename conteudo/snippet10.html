Criando um joguinho

Esse tutorial mostra como programar um joguinho simples com a linguagem python.

\nPara seguir esse tutorial é preciso que o python esteja instalado.
\nAlém disso o módulo pygame também é utilizado.

Inicialização e cenário

import pygame\n\npygame.init()\n\ngameDisplay = pygame.display.set_mode((840,210)) #tamanho do cenario\npygame.display.set_caption('Endless Runner') #titulo da janelinha\n\nclock = pygame.time.Clock()\ngameover = False\n\nwhile not gameover: #enquanto o jogo estiver rolando\n  for event in pygame.event.get(): #loop de eventos do windows\n      if event.type == pygame.QUIT: #se o user clicou no x da janelinha do jogo no windows\n          gameover = True\n\n  gameDisplay.fill((200,200,250)) #preenche o cenario com azul (200,200,250)\n\n  pygame.draw.rect(gameDisplay, (110,110,110), [0,170,840,40]) #desenha o chao do cenario: 110,110,110 e a cor e 0,170,840,40 sao as coordenadas do retangulo\n\n  pygame.display.update() #atualiza a tela do jogo\n  clock.tick(120) #delay de 120 milissegundos para rodar o gameloop de novo\n\npygame.quit()\nquit()
\nEsse código é a base do tutorial. Salve e execute o arquivo para visualizar o cenário do jogo.

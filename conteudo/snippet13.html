Aplicativo de Celular

Aqui vai uma explicação detalhada do desenvolvimento de um aplicativo de celular.

Iniciando o projeto randomExpressions

Para começar crie um projeto novo do tipo 'Activity em Branco'.

\n\nO package name pode ser random.expressions

AndroidManifest.xml

O android:theme é modelo antigo.
\nO ícone vai dentro da pasta res/drawable
<?xml version="1.0" encoding="utf-8"?>\n<manifest xmlns:android="http://schemas.android.com/apk/res/android">\n\n	<application\n		android:allowBackup="true"\n		android:icon="@drawable/icon"\n		android:label="expressions"\n		android:theme="@android:style/Theme.Light.NoTitleBar"\n		android:resizeableActivity="true">\n		<activity\n			android:exported="true"\n			android:name=".MainActivity"\n			android:label="expressions">\n			<intent-filter>\n				<action android:name="android.intent.action.MAIN" />\n				<category android:name="android.intent.category.LAUNCHER" />\n			</intent-filter>\n		</activity>\n	</application>\n\n</manifest>

Pasta raw

Dentro da pasta /main/res/ vão 13 imagens e um arquivo html.
\n\nSão arquivos que contêem os pedaços das caras que são sorteadas para serem exibidas na tela.

\n\nExtraia e coloque o conteúdo na pasta /main/res/raw/

Webview

O arquivo html contém código css e javascript que misturam as imagens para gerar expressões.
\nEsse arquivo é renderizado em uma webview que é um recurso do desenvolvimento android.
\nUma webview é como um pedaço de um navegador browser. A webview renderiza código html, css e js e exibe dentro do app.

\n\nPosteriormente código java tira screenshot da tela html que está renderizada na webview.

Salvando screenshot programaticamente

expressionView.setDrawingCacheEnabled(true);\nBitmap bitmap=Bitmap.createBitmap(expressionView.getDrawingCache());\nexpressionView.setDrawingCacheEnabled(false);\nIntent intent=new Intent("android.intent.action.SEND");\nintent.setType("image/jpeg");\nintent.putExtra("android.intent.extra.STREAM",Uri.parse(MediaStore.Images.Media.insertImage(getContentResolver(),bitmap,String.valueOf((long)System.currentTimeMillis()),"expression")));\nMainActivity.this.startActivity(Intent.createChooser(intent,""));\n
\nEsse código faz o app tirar um screenshot quando o user clica no botão.
\nO screenshot é salvo e aparece a opção de compartilhar.

LinearLayout

LinearLayout é um elemento android que posiciona componentes na tela do aplicativo.
LinearLayout linearLayout=new LinearLayout(this);\nlinearLayout.setOrientation(linearLayout.VERTICAL);\n

Webview

Webview é um pedaço de uma janelinha de um navegador que vai no linearLayout.
WebView expressionView=new WebView(this);\nexpressionView.getSettings().setJavaScriptEnabled(true);\nexpressionView.loadUrl("file:///android_res/raw/index.html");\nlinearLayout.addView(expressionView);\n

ScrollView

O ScrollView serve para uma situação de quando a tela precisa ser rolada.
\nNesse caso provavelmente isso não acontece mas existem situações em que há mais elementos no linearLayout e para que o app exiba todos o linearLayout vai dentro da ScrollView.
ScrollView scrollView=new ScrollView(this);\nscrollView.setBackgroundColor(new Color().parseColor("#e1e8f0"));\nscrollView.addView(linearLayout);\n\nsetContentView(scrollView);\n

Interruptor

Quero explicar como um arquivo fica no pendrive.
\nE quero que essa explicação seja simples.

\nPra começar precisamos entender o que é um bit.
\nQuero explicar o que é um bit e quero que essa explicação seja simples.

\nUm bit é um interruptor desses de parede... só que bem menor.

\n

Bit

Uma caracteristica dos interruptores de parede é que estão ligados ou estão desligados.
\nNão tem meio termo.
\nOu a luz tá acesa, ou a luz está apagada.
\nAssim é o bit.
\nOu sim ou não, ou zero ou um, ou a eletricidade passa ou a eletricidade não passa.

\n\nCom 8 interruptores de parede é possível 256 configurações do tipo:
\n1) Todos interruptores desligados
\n2) Todos interruptores desligados, exceto o ultimo
\n3) Todos interruptores desligados, exceto o penultimo
\n4) Todos interruptores desligados, exceto o penultimo e o ultimo
\n5) Todos interruptores desligados, exceto o antepenultimo
...
\n256) Todos interruptores ligados

\n\n

Byte

E 8 bits formam um byte. Um byte armazena uma informação entre 256 possibilidades.
\nPode ser um número, uma letra, uma cor, um som... mas sempre é um entre 256.
\nÉ como se um byte fosse 8 interruptores bem pequenos que podem estar ligados ou desligados.
\nCada um dos interruptores do byte pode estar ligado ou desligado.

\n

PenDrive

Nos pendrives antigos cabia 1024 MegaBytes.
\nCada MegaByte armazena 1024 KByte.
\nCada KByte é formado por 1024 Bytes.
\nQue são os 8 interruptores que descrevi.

\n

Arquivo

Vamos considerar que nesse pendrive está armazenada uma imagem.
\nOs formatos de imagem comuns são jpg, bmp, gif mas pra essa situação especifica a imagem está armazenada diretamente...

\n

Arquivo

Vamos considerar que nesse tipo de formato (imaginário, inventado apenas facilitar essa explicação) os três primeiros bytes do arquivo são para o primeiro ponto de cor da imagem (o primeiro pixel, no canto superior direito da imagem).
\nCada um desses três bytes armazena um valor entre 0 e 255. (cada bit desse byte está ligado ou está desligado)
\nVamos considerar que o primeiro dos três bytes se refere a quantidade de cor vermelha no pixel.
\nVamos considerar que cada cor pode ser formada a partir de determinada quantidade de cor vermelha, determinada quantidade de cor verde e determinada quantidade de cor azul.
\nSendo assim a cor do primeiro pixel ocupa 3 bytes ou 24 bits.
\nSe a imagem tiver 1024x768 a imagem vai ocupar 1024x768x3 bytes no pendrive.

\n

Especificação do formato do arquivo

É importante o dispositivo(máquina) que lê o pendrive.
\nO dispositivo(máquina) deve entender a padronização.
\nDeve saber que para cada cor são utilizados três bytes e que essa imagem tem um tamanho específico.

\n\nNa realidade tudo é um pouco mais complicado, mas espero que esse artigo nos ajude a entender um pouco mais.

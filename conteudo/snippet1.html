Programando um joguinho de celular

Esse tutorial se propõe a demonstrar como programar o joguinho sem framework ou game-engine.
\nProgramação java (nível intermediário)

Imagens do Jogo

Nesse link estão todas as imagens utilizadas no jogo.

\nA maioria dessas imagens é disponibilizadas pelo site https://kenney.nl

\nSão poucas imagens porque esse é um jogo pequeno.

Iniciando o projeto

Na hora de iniciar o projeto escolha a opção 'activity em branco' e dê o nome 'zombie.waves' ao pacote.

\n\nDepois que o compilador gerou a base do app, deve haver uma pasta /main/ que contém uma pasta /java/ e uma pasta /res/ e um Manifest

\n\n

Editando o Manifest

O arquivo AndroidManifest.xml armazena informações sobre o app, mas esse não é um arquivo de código-fonte java.
\nÉ como um 'arquivo de configuração'.\n
<?xml version="1.0" encoding="utf-8"?>\n<manifest xmlns:android="http://schemas.android.com/apk/res/android">\n\n	<application\n			android:allowBackup="true"\n			android:label="zombie waves"\n			android:theme="@android:style/Theme.Black.NoTitleBar.Fullscreen"\n			android:icon="@drawable/attack">\n		<activity\n				android:name=".MainActivity"\n				android:screenOrientation="landscape"\n				android:exported="true">\n			<intent-filter>\n				<action android:name="android.intent.action.MAIN"/>\n				<category android:name="android.intent.category.LAUNCHER"/>\n			</intent-filter>\n		</activity>\n	</application>\n</manifest>
\n\nA linha icon ... attack vai apresentar erro porque a não tem uma imagem chamada 'attack.png' na pasta /drawable/
\nA imagem attack.png é a imagem do punho atacando.
\nEssa imagem é um botão no jogo e também é (definida no manifest) o ícone do app.

\n\nDá para deixar o ícone 'default' se você não quiser alterar essa parte do arquivo manifest.

\n\nAs alterações significativas para esse projeto são:\n
  • style Theme noTitleBar Fullscreen
    • \n
  • screenOrientation landscape

    • \n\nPode ser necessário incluir mais algumas linhas nesse arquivo (ou excluir algumas) dependendo do compilador/versão que voce usar.

    \n\nEdite esse arquivo até que não haja erros que impeçam que o executável seja gerado.

    Incluindo as imagens no projeto

    Dentro da pasta /main/ existe a pasta /res/ e dentro dela várias outras pastas.

    \nNessas pastas estão os resources (recursos) do app.

    \nRecursos como imagens, sons, arquivos, textos.

    \n\nQuando o compilador gera a base do app esses recursos são gerados. Mas nesse projeto não precisaremos deles.
    \nTodos os recursos do jogo são as imagens que estão dentro da pasta drawable que está linkada no começo do tutorial

    \n\n

    \n\nExclua todas essas pastas de dentro da pasta /res/
    \nColoque no lugar a pasta drawable (descompactada)

    \n\nDepois de excluir pode ser preciso editar mais um pouco o arquivo manifest.

    Colocando Zumbis na Tela

    \nPor isso existe a variável moveDelay
